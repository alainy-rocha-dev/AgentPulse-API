Decisões Arquiteturais Fundamentais

Desacoplamento Assíncrono

A API aceita requisições longas e responde imediatamente em menos de 500ms com HTTP 202 Accepted. O trabalho pesado é delegado ao Celery/Redis.

Reparo Anti-Alucinação

Garantia de saída estruturada: se o LLM alucinar ou violar o schema JSON, o RepairLoop Service envia o erro de validação de volta para o LLM corrigir a sintaxe em até 3 tentativas.

Persistência Resiliente

Todas as atualizações de estado da tarefa usam o Tenacity para tentar novamente em caso de falha de conexão temporária com o banco de dados.
