Feature 004: PostgreSQL Persistence & Docker Compose

Camada de persistência relacional com SQLAlchemy/Alembic e ambiente containerizado multi-serviço.

Objetivo

Prover suporte completo a banco de dados relacional PostgreSQL com migrações automáticas de schema DDL no startup e orquestração Docker Compose com volumes nomeados persistentes.

Serviços Docker Orquestrados

1. `api` (FastAPI)

Interface HTTP web rodando Uvicorn, conectada ao PostgreSQL via ASYNC_DATABASE_URL e despachando para o Redis.

2. `worker` (Celery)

Consumidor das tarefas assíncronas do Redis, executando o fluxo de agentes e gravando o estado no PostgreSQL.

3. `db` (PostgreSQL 16)

Banco relacional com volume nomeado postgres_data e verificação de saúde via pg_isready.

4. `redis` (Redis 7)

Broker de mensageria com healthcheck redis-cli ping garantindo ordem de subida dos containers.
