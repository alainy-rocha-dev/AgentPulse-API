Feature 003: Task Queue Broker (Celery + Redis)

Infraestrutura de enfileiramento e consumo assíncrono em segundo plano com garantia de entrega e retries.

Objetivo

Gerenciar o enfileiramento de tarefas pesadas com Redis e Workers Celery, aplicando task_acks_late=True e retentativas síncronas resilientes com tenacity.

Configurações do Celery Broker

Parâmetro Valor Impacto / Motivação
task_acks_late True A confirmação só ocorre após a conclusão da execução. Se o container cair no meio, a tarefa não é perdida.
task_time_limit 300s (5 min) Previne tarefas presas indefinidamente interrompendo execuções com timeout.
result_backend Redis / PostgreSQL Armazena estados intermediários e resultados das tarefas.
