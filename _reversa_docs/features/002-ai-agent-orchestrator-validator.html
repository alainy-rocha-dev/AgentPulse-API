Feature 002: AI Agent Orchestrator & Validator

Cadeia de execução de agentes de IA com validação estrita de esquemas Pydantic e Loop de Reparo Anti-alucinação.

Objetivo

Garantir que a resposta gerada pelos modelos de linguagem (LLM) seja estritamente determinística e compatível com o contrato JSON definido pela aplicação.

Mecanismo do Repair Loop Service

1. Execução Inicial

O prompt do agente é despachado para o LLM solicitando saída no formato JSON especificado pelo schema Pydantic.

2. Validação Pydantic

A resposta é validada sintaticamente contra AnalysisOutputSchema. Se válida, o resultado é aceito imediatamente.

3. Loop de Correção (Até 3 tentativas)

Se houver erro sintático ou campo ausente, a mensagem de erro detalhada do Pydantic é injetada no prompt como feedback para o LLM corrigir a geração.
