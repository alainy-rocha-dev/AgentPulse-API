Feature 001: API Gateway & Gerenciamento de Tarefas

Entrega da porta de entrada HTTP FastAPI com validação de payload Pydantic e respostas assíncronas 202 Accepted.

Objetivo

Prover uma API HTTP de alta performance para submissão de tarefas de IA de longa duração, retornando resposta imediata com ID de acompanhamento para evitar timeouts do cliente.

Endpoints Implementados

Método Rota Status HTTP Descrição
POST /api/v1/tasks 202 Accepted Recebe o tipo da tarefa e o payload JSON. Retorna task_id e status queued. Valida tamanho máximo de 10 MB (HTTP 413).
GET /api/v1/tasks/{task_id} 200 OK / 404 Retorna o estado atual da tarefa (queued, running, completed, failed) e os resultados estruturados.
