Módulos de Código e Responsabilidades

Inventário detalhado dos principais arquivos Python e artefatos de infraestrutura da solução.

Módulo / Arquivo Camada Descrição e Responsabilidade
app/main.py API Gateway Aplicação principal FastAPI, configuração de CORS, rotas /api/v1 e middleware de validação de tamanho máximo de payload (10 MB).
app/api/v1/endpoints/tasks.py Controllers Endpoints HTTP. POST /tasks valida o payload e enfileira no Celery. GET /tasks/{task_id} consulta o estado e resultado.
app/services/repair_loop.py AI Engine Serviço responsável por validar saídas estruturadas com Pydantic e re-executar prompts com os erros de sintaxe encontrados (Loop de Reparo Anti-alucinação).
app/worker.py Background Worker Processamento em segundo plano via Celery. Gerencia a transição de status (queued → running → completed / failed) com retries.
app/core/database.py Database Core Instanciação do AsyncEngine SQLAlchemy, AsyncSessionLocal para injeção de dependência no FastAPI e definição da Base declarativa.
app/models/task.py ORM Model Mapeamento ORM da tabela tasks no PostgreSQL com UUID primário, campos JSONB e timestamps timezone-aware.
alembic/versions/001_create_tasks_table.py Migrations Migração DDL inicial do Alembic criando a tabela tasks e seus índices compostos.
docker-compose.yml Orquestração Definição multi-container dos serviços api, worker, db (PostgreSQL 16) e redis com healthchecks.
