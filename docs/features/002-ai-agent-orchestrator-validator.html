Feature 002: AI Orchestrator & Repair Loop

Orquestração de agentes de IA com validação de esquema Pydantic e loop de reparo anti-alucinação de 3 tentativas.

🤖 Validação Pydantic

Garantia de tipo em todas as entradas e saídas do LLM. Se a resposta contiver um JSON malformado, o validador captura os erros específicos.

🔄 Loop de Reparo Anti-Alucinação

O RepairLoopService realiza até 3 re-tentativas enviando o traceback de erro de volta ao modelo para auto-correção sem interromper o fluxo.
