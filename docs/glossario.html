Glossário de Termos e Conceitos Técnicos

Definição de padrões de arquitetura, ferramentas e conceitos utilizados no projeto.

⚡ HTTP 202 Accepted

Código de status HTTP indicando que a requisição foi aceita para processamento assíncrono, mas a execução ainda não foi concluída. Devolve um task_id para acompanhamento.

🤖 Repair Loop (Loop de Reparo)

Mecanismo anti-alucinação onde erros de validação sintática do Pydantic são enviados de volta ao modelo de linguagem (LLM) para corrigir o formato JSON sem falhar a requisição.

🔄 Acks Late (Celery)

Configuração do Celery em que a confirmação da tarefa só é enviada ao Redis após a conclusão com sucesso da execução, prevenindo perda de tarefas se o worker cair.

🛡️ Tenacity

Biblioteca de retentativas em Python com política de backoff exponencial utilizada para garantir que operações no banco PostgreSQL sobrevivam a pequenas instabilidades de rede.

🐘 Alembic

Ferramenta de migração de banco de dados para SQLAlchemy. Permite controle de versão evolutivo de schemas relacionais PostgreSQL.

🐳 pg_isready

Utilitário do PostgreSQL usado pelo Docker Compose no healthcheck para verificar se o banco de dados está pronto para receber conexões antes de liberar o startup da API e Worker.
